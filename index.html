XOL programming language

Сброс станции

Скопируйте команду для своей системы и запустите её в терминале из папки, внутри которой должна находиться станция.

Важно: команда полностью удалит папку xol-station в текущей директории и заменит её чистой копией. Несохранённые решения участников внутри этой папки будут удалены.
Windows

PowerShell

Подходит для PowerShell и обычного CMD. Нужен только встроенный Windows PowerShell.

powershell -NoProfile -ExecutionPolicy Bypass -Command "irm https://kroune.github.io/xol-station/reset.ps1 | iex"
Linux

Терминал

Используется sh и доступный curl или wget. Git и Python не нужны.

sh -c 'if command -v curl >/dev/null 2>&1; then curl -fsSL https://kroune.github.io/xol-station/reset.sh | sh; elif command -v wget >/dev/null 2>&1; then wget -qO- https://kroune.github.io/xol-station/reset.sh | sh; else printf "Ошибка: нужен curl или wget. Установите один из них.\n" >&2; exit 1; fi'
macOS

Terminal / iTerm

Работает в стандартном Terminal. sh и curl уже входят в macOS.

sh -c 'if command -v curl >/dev/null 2>&1; then curl -fsSL https://kroune.github.io/xol-station/reset.sh | sh; elif command -v wget >/dev/null 2>&1; then wget -qO- https://kroune.github.io/xol-station/reset.sh | sh; else printf "Ошибка: нужен curl или wget. Установите один из них.\n" >&2; exit 1; fi'

Что происходит после запуска

  1. Скрипт скачивает актуальные задачи и проверяет архив.
  2. Старая папка xol-station удаляется только после успешной загрузки.
  3. Создаются папки easy, medium и hard с пустыми main.xol.
  4. Для проверки решений используются команды node xol-station/easy/test.js, node xol-station/medium/test.js и node xol-station/hard/test.js.

Для сброса нужен интернет. Для тестов нужен Node.js 20+; npm и исходный репозиторий языка не нужны.
